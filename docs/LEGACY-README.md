## 这是什么

一个**单文件离线班级管理软件**（`dist/班序-班级管理.html`，打开即用，无需安装、无需联网）：

1. Excel 导入学生名单与考试成绩（内置 SheetJS 0.20.3 读取 xlsx，也支持直接读学校"班级全学科成绩汇总"表）
2. 座位编排：8 列 × 7 排 = 56 常规座 + 中央加座 1 列 2 座 = 共 **58 座**（可在顶部切回 6 排 = 50 座），学生是模块，拖动吸附，拖到已有人的座位自动交换
3. 座位表上可切换显示某次考试的总分/单科成绩，用于排位
4. 大组轮换（第一→第二→第三→第四→第一，组内排数与左右位置不变，中央加座不参与）
5. 按成绩分类随机点名（优秀前 30%、中等中间 40%、后进生后 30%，并列同分取平均名次；支持按单次考试或最近 3/5 次、全部考试的平均分；支持"本轮不重复"）
6. 考试成绩在线预览，可按学号、姓名、任意一科点表头升降序排序
7. 违纪情况页：按学生列出违纪次数与类型明细（无违纪不显示），点行查看明细；支持从备忘录文字快速导入
8. 数据只存浏览器 localStorage，支持导出/恢复备份、撤销（30 步）、打印/存 PDF

## 怎么跑

- 直接用浏览器打开 `dist/班序-班级管理.html`（Chrome / Edge / Safari 均可，离线）。
- 建议固定同一个浏览器、同一个文件路径，否则 localStorage 里的班级数据换位置会读不到。
- 改了 `app/app.html`（结构与逻辑都在里面）后，执行 `python3 app/build.py` 重新打包到 `dist/`，它会顺带同步 `app/app.js`。
- 测试：`cd app/test && npm i`（只需一次），然后 `for t in check upgrade exam-date discipline discipline-types preview-sort call-average row7; do node app/test/$t.cjs; done`。
