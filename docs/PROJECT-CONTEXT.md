# 项目上下文（给接手的 agent 看）

## 2026-10 架构升级：单文件 → 前后端项目

- 前端：`frontend/`，TypeScript + 浏览器原生 ESM，`npm run build`（tsc + 静态复制）输出 `frontend/dist`。
- 后端：`backend/`，Python 3.9 + FastAPI + SQLite（`app/main.py` 工厂、`app/api.py` 路由、`app/repository.py` SQL、`app/domain.py` 校验）。
- 后端在 `frontend/dist` 存在时挂载为静态站点，因此 `uvicorn app.main:app --app-dir backend --port 8000` 一个端口即可用。
- 旧单文件版本保留在 `app/`、`dist/`（历史参考，不再维护）。
- 数据从 localStorage 迁移到 SQLite（`backend/data/banxu.sqlite3`）；前端不再本地存储业务数据，只保留 30 步撤销快照。
- 测试：`backend` 用 pytest（45 项）；`frontend` 用 Node 内置 test runner 跑 `frontend/tests/*.test.mjs`（24 项，需先 build）。

## 一句话

当前形态为前后端项目（见上），面向高一 20 班（50 人）。核心诉求：Excel 导入名单与成绩、拖拽吸附排座、座位表叠加成绩显示，另有按成绩点名与违纪记录。

## 需求原话（第一条用户消息）

> 1、能够导入班级学生名单和每次考试的成绩（可以自动读取excel表的内容）可以通过制作模板实现
> 2、能够对班级学生的座位进行安排，（把每个学生变成一个可以拖动的模块，拖动到某个位置实现吸附效果）班级的座位是共8列，每两列为一组，每组六排，其中班级中央还要再额外加两个人为一列
> 3、能够在座位表格中选择是否显示学生的某次考试成绩（用于排位置）

## 已实现（与代码对应）

| 能力 | 说明 |
|---|---|
| 名单导入 | 读 xlsx，按学号唯一匹配；重复导入按学号更新、新学生追加，不删其他人 |
| 成绩导入 | 每次导入创建独立考试，考试名与**考试时间**均必填、可改名改日期；自动识别学校"全学科汇总"表的双行表头，取各科得分/校次/班次/总分排名；也支持学校「学生成绩单」PDF（`app/pdf_exam.py` 按文字坐标解析姓名/总分，前端 `lib/pdf-exam.ts` 按姓名匹配，单科导入总分，逐题得分不入库；缺少班次的科目按分数自动补算班次，见 `domain.compute_class_ranks()` 与 `repository.fill_missing_class_ranks()`） |
| 考试时间 | 存为 `YYYY-MM-DD`；所有考试按时间倒序（同日后导入在前），考试档案/点名下拉/成绩气泡统一用 `sortedExams()`；旧数据在载入时由 `normalizeExamDates()` 规范化，无法解析的排末尾 |
| 十科体系 | 语文 数学 英语 物理 化学 生物 政治 历史 地理 技术 + 总分；模板自动带当前班级学号姓名 |
| 座位布局 | `state.rows` 可切 6/7 排：7 排=56 常规+2 加座=**58 座**（默认），6 排=48+2=50 座；第 4/5 列之间加一列 2 座（默认第 5、6 排，可改相邻两排，7 排时可到第 6–7 排）；排座填充顺序 `fillOrderFor()` 会先填常规座与加座再进第 7 排；减少排数时第 7 排学生经确认回到待安排区 |
| 交互 | 拖动吸附、拖到已占座位自动交换、按名单顺序填空座、随机填空座、清空、导出座位 Excel |
| 成绩显示 | 座位表勾选"显示成绩"后，可选 `state.seatRange`（单次考试 / 最近 3、5 次平均 / 全部考试平均）与 `state.subject` 科目；姓名下方显示该口径的成绩与班次排名（`lib/ranking.ts` 的 `scoreRanking()`，缺考不计分母；平均模式只统计有该科的考试） |
| 大组轮换 | 面对黑板从左到右：第四组、第三组、中央加座、第二组、第一组；轮换后组内排数与左右位置不变，中央加座与待安排学生不参与，可撤销，四次回原位 |
| 预览排序 | 成绩在线预览点表头按学号/姓名/单科排序，升降序切换，缺考恒排最后，可与搜索叠加 |
| 点名统计方式 | `state.callRange`：single / recent3 / recent5 / all；平均取所选科目的有效成绩（缺考不计分母），`callScore()` 统一算分；科目用 `state.callSubject`，与座位表 `state.seatRange` / `state.subject` 解耦 |
| 随机点名 | 按有效成绩分档（优秀 ≤30%、中等、后进 ≥70%，用平均名次 `(rank-0.5)/n` 定位），0 分算有效，缺考/未录入单列"暂无成绩"；跨分类本轮不重复 |
| 违纪记录 | 红色气泡内 8 个类型按钮（默认晚自习违纪）+ 日期 + 可选备注；可逐条删除、撤销上一条、恢复刚删除 |
| 违纪情况页 | 侧栏 `data-page="discipline"` 独立页面：`disciplinePageRows()` 只列有记录的学生，按次数降序，展示次数/最近日期/类型明细，点行开气泡；支持全部/30天/7天与搜索，快速导入入口在此页 |
| 违纪快速导入 | 备忘录文字按行解析：`parseDiscText()` 识别日期（YYYY-MM-DD／M月D日／M/D，缺省用默认日期）、姓名（支持一行多人）、类型（`DISC_ALIASES` 简称，长别名优先避免“静校”被当成“晚自习”）、余下文字作备注；无效行标红不导入，重复条目自动跳过 |
| 数据 | 纯 localStorage，不上传、不写回 Excel；导出/恢复备份；撤销 30 步；打印/存 PDF |

## 代码约定（改之前先看）

- 单文件交付：`app/app.html` + `app/app.js` + `app/vendor/xlsx.full.min.js` 需内联为一个 html 输出到 `dist/`。**别改成多文件引用**，用户靠双击单文件使用。
- 版本升级走 `app/upgrade.py`（旧数据/localStorage 结构迁移），改数据结构必须同步改它并跑 `app/test/upgrade.cjs`。
- 校验用 `app/test/check.cjs`、`app/test/upgrade.cjs`、`app/test/exam-date.cjs`；打包用 `python3 app/build.py`（禁止手改 `dist/`）。
- 中文 UI，术语沿用："班序""待安排区""加座""大组轮换""本轮不重复"。
- 班级规模 50 人，座位容量刚好 50；任何布局改动都要保证 50 座不变。

## 待办 / 可继续的方向

1. **多班级切换**：当前是"单设备单班级"，换班靠导出/恢复备份切换，可以考虑做班级档案列表。
2. **无云同步**：浏览器清缓存或换设备会丢数据，先靠手动备份；如要做同步需引入后端。
3. **`app/test/node_modules` 未迁移**：要跑测试先 `cd app/test && npm i`。
4. 随机点名的分档比例是硬编码 30/40/30，可按需做成可配置。

## 已知坑

- 学号必须是唯一且固定的**文本**编号，否则成绩按姓名匹配时重名会串。
- 缺考/未考/未录入/免考/破折号 = 无成绩；0 分是有效成绩，别混。
- 有缺失科目时自动总分留空，不做部分求和。
- 改本地存储位置（移动 html 文件）会让浏览器读不到旧数据，先导出备份。
