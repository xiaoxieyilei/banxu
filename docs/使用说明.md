# 班序 · 使用说明

> 班序是一个给班主任使用的本地班级管理工具：导入名单与成绩、拖拽排座、按成绩点名、记录违纪，并在座位表上直接看成绩与排名。数据保存在你自己的电脑里，不上传云端。

项目主页：<https://github.com/xiaoxieyilei/banxu>

---

## 1. 功能一览

| 模块 | 能做什么 |
|---|---|
| 学生名单 | Excel 导入、手动增删改、导出 |
| 考试成绩 | 导入 Excel 模板、学校成绩汇总表、学校成绩单 PDF；查看单次明细与学科趋势 |
| 座位安排 | 拖拽/点选排座、大组轮换、中央加座、打印；按单次考试或多次平均显示成绩与班次 |
| 随机点名 | 按成绩分档抽取，支持单次/最近 3、5 次/全部平均，本轮不重复 |
| 违纪情况 | 个人违纪记录、寝室违纪统计、备忘录批量导入 |
| 数据安全 | 本地 SQLite、手动/自动备份、全局撤销（⌘Z） |
| 手机访问 | 同一 Wi-Fi 或 Tailscale 下用手机浏览器访问 |
| 自动更新 | 软件内检查 GitHub 新版本，一键下载、重建并重启 |

## 2. 安装

### 2.1 环境要求

- macOS、Windows 10/11、Linux
- Windows 需要 Python 3.9+ 与 Node.js 20+；macOS/Linux 同样需要
- Python 3.9+
- Node.js 20+（构建前端用）
- 首次安装需要联网下载依赖

### 2.2 直接下载安装包（macOS，无需环境）

在 <https://github.com/xiaoxieyilei/banxu/releases> 下载最新的 `banxu-macOS-arm64.zip`：

1. 解压，把 `班序.app` 拖进「应用程序」；
2. 首次打开若提示“无法验证开发者”，右键应用 → **打开**；
3. 数据在 `~/Library/Application Support/班序`，备份在 `~/Documents/班序备份（安装版）`。

Windows / Intel Mac / Linux 的安装包尚未提供，请先用源码方式启动（见下一节）。

### 2.3 获取源码

在 GitHub 项目页点击 **Code → Download ZIP**，解压到任意目录；或者：

```bash
git clone https://github.com/xiaoxieyilei/banxu.git
cd banxu
```

### 2.4 首次启动

- macOS：双击项目根目录的 **`启动班序.command`**；
- Windows：双击 **`启动班序.bat`**；
- Linux：终端运行 `./run.sh`。

首次启动会自动：

1. 创建 Python 虚拟环境 `backend/.venv`；
2. 安装后端依赖（含 PDF 解析、FastAPI 等）；
3. 安装前端依赖并构建 `frontend/dist`；
4. 启动本地服务并打开 <http://127.0.0.1:8000>。

也可以在终端运行：

```bash
./run.sh
```

> 首次安装可能需要几分钟；终端窗口关闭后服务就停止。

### 2.4 访问口令

首次启动会在 `backend/data/.password` 生成访问口令。打开页面后输入口令即可登录。

```bash
cat backend/data/.password
```

也可以在启动时指定：

```bash
BANXU_PASSWORD=你的口令 ./run.sh
```

## 3. 学生名单

### 3.1 导入 Excel

1. 点击右上角 **「↓ 下载 Excel 模板」**；
2. 按模板填写学号、姓名、性别（可选）、备注（可选）；
3. 点击 **「＋ 导入学生名单」**，选择文件。

规则：

- 以**学号**为唯一标识：已存在的学号更新资料，新学号追加，未列出的学生保留；
- 同一个文件里学号不能重复；
- 支持 `.xlsx / .xls / .csv`。

### 3.2 手动维护

在「学生名单」页可以添加、编辑、删除学生。删除学生会同时删除其座位、成绩和违纪记录；删除后可以用顶部「↶ 撤销」或 ⌘Z 恢复。

## 4. 考试成绩

### 4.1 支持的文件类型

| 类型 | 说明 |
|---|---|
| 班序 Excel 模板 | 一行一名学生，各科分数列，可带总分 |
| 学校“班级全学科成绩汇总”表 | 两行表头，读取得分/校次/班次 |
| 学校单科成绩表 | 例如语文限时练、英语周练；按姓名匹配 |
| 学校「学生成绩单」PDF | 目前支持 TFB-SCHOOL 风格的学生成绩单（带文字层，非扫描件） |

PDF 会自动读取：考试名、科目、满分、每位学生的总分；逐题得分暂不保存。

### 4.2 导入步骤

「考试成绩 → 导入考试成绩」：

1. 选择文件；
2. 核对考试名称、考试时间；
3. PDF 可修改自动识别的科目；
4. 查看预览；
5. 点击「确认导入」。

如果已经存在**同名同日期**的考试，可以勾选「覆盖同名同日期考试」直接替换该场成绩；不会新增重复考试，也不会影响座位表当前选中的考试。

### 4.3 自动班次

导入的成绩如果缺少班次：

- 软件会按本班该科分数自动计算班次；
- 同分同名次（例如 98、98、97 → 1、1、3）；
- 缺考不参与排名；
- 学校提供的校次不会被伪造，没有就显示「—」。

### 4.4 满分与百分制平均

在「考试成绩 → 修改信息（✎）」里可以为每科填写满分。PDF 导入会自动带入满分。

座位表使用“平均”模式时：

- 参与统计的**每一场**考试都有该科满分 → 先按满分折算成百分制再平均；
- 只要有一场没填满分 → 按原始分平均，避免把 100 分制和 120 分制混在一起。

### 4.5 修改与删除

- 「修改信息」可改名称、日期、各科满分；
- 「导出」把该场成绩导出为 Excel；
- 「删除」会删除该场成绩，可用撤销恢复。

## 5. 座位安排

### 5.1 基本操作

- 把学生从右侧「待安排」拖到座位；
- 拖到已有学生的座位会自动交换；
- 也可以先点学生、再点目标座位；
- 拖回「待安排」区可移出座位；
- 支持 6/7 排、中央加座位置调整、大组轮换、撤销、打印。

### 5.2 显示成绩

勾选「显示成绩」后：

- **统计方式**：单次考试 / 最近 3 次平均 / 最近 5 次平均 / 全部考试平均；
- **考试**：单次模式下选择具体考试；
- **科目**：总分或任意学科（如数学）。

座位卡姓名下方显示：

- 单次考试：`96 分` + `班次 7`；
- 平均模式：`均分 77.5%`（满分齐全时）或 `均分 84` + 班次；
- 悬停可看到统计场次、排名来源（学校数据/按分数计算）。

单次考试如果学校导入了官方班次，会优先使用官方班次；否则按当前成绩计算。

### 5.3 打印

工具栏「打印」会隐藏其他界面，只打印座位表；秋季 7 排布局会自动缩小字号。

## 6. 随机点名

- 可按优秀前 30%、中间 40%、后进 30% 或全部名单抽取；
- 支持单次考试、最近 3/5 次、全部考试平均；
- 可选择科目；
- 勾选「本轮不重复」后，同一轮不会重复抽到同一人；
- 「开始新一轮」重置本轮记录。

---

## 7. 违纪记录

### 7.1 个人违纪

在座位表点击学生，左侧红色气泡中添加：

- 8 种类型（默认晚自习违纪）；
- 日期；
- 备注（可选）。

可删除单条、撤销上一条、恢复刚删除。

### 7.2 寝室违纪

「违纪情况 → 寝室违纪统计」：

- 支持添加寝室、编辑成员与寝室号；
- 可整间或只勾选个别成员登记一次违纪，也可撤销整次；
- 学生调寝后，历史事件仍留在原寝室，并标注「已调出」。

### 7.3 批量导入

「快速导入」支持粘贴备忘录文字，软件会识别姓名、日期、类型和备注；同一天多条记录可以逐条保留，也可以勾选跳过重复。

## 8. 数据与备份

- 数据库：`backend/data/banxu.sqlite3`
- 访问口令：`backend/data/.password`
- 自动备份：每天 **21:30** 检查，有变化才写入当前用户的 **文档目录/班序备份/班序备份-YYYY-MM-DD.json**（Windows 通常是 `C:\Users\<用户名>\Documents\班序备份`）；软件启动时也会补一次，避免当天没开机漏备。
- 导入考试成绩后会立即写一份备份。
- 页面右上角「备份到文件夹」可随时手动备份；「导出备份」下载 JSON。
- 数据库、备份、日志、口令文件权限为仅本人可读写。
- 「恢复备份」会整库替换当前数据，操作前建议先导出一次。

## 9. 手机访问

普通启动默认只监听 `127.0.0.1`，手机访问不到。要让手机访问：

1. macOS 双击 **`启动班序（手机访问）.command`**，Windows 双击 **`启动班序（手机访问）.bat`**（监听 `0.0.0.0:8000`）；
2. 电脑和手机连接同一 Wi-Fi，或都登录同一个 Tailscale 账号；
3. 手机浏览器打开 `http://<电脑IP>:8000`，输入访问口令；
4. Safari 分享 → 添加到主屏幕，可当 App 使用。

安全提醒：

- 只在可信 Wi-Fi / Tailscale 下使用；
- 不要把 8000 端口直接映射到公网；
- 访问口令不要发给无关人员。

## 10. 自动更新

### 10.1 使用

顶部工具栏「检查更新」：

- 有新版本时按钮显示「更新到 vX.Y.Z」；
- 点击后查看更新说明，点「立即更新」；
- 源码启动版：软件会自动下载 GitHub 上的新版本、安装依赖、构建前端、重启服务，页面自动刷新；
- 安装包版：按钮会检查版本，并提示到 GitHub Releases 下载新的安装包覆盖旧版本（数据不受影响）。

### 10.2 更新会保留什么

更新只替换程序源码，保留：

- `backend/data/`（数据库、口令、更新日志）
- `backend/.venv/`
- `frontend/node_modules/`
- `backups/`
- `update.json`（更新仓库配置）
- 个人备份与导出文件

更新前会把当前源码备份到 `backups/update-时间戳/`，构建失败会尝试恢复源码。

### 10.3 更新失败怎么办

1. 查看 `backend/data/update.log`；
2. 若服务没有自动启动，运行一次 `./run.sh`；
3. 更新前源码备份在 `backups/update-*`，必要时可手动恢复。

### 10.4 更新仓库配置

更新仓库由项目根目录 `update.json` 决定：

```json
{
  "repo": "xiaoxieyilei/banxu"
}
```

只允许从该仓库的 Release/Tag 更新，前端不能指定任意下载地址。仓库需要发布 Release 或打 Tag（例如 `v2.2.0`）才能被检测到。

## 11. 开机自启（可选，仅 macOS 源码版）

先手动运行一次 `./run.sh` 完成依赖与构建，然后：

```bash
./scripts/install-launchagent.command                 # 只本机访问
ALLOW_PHONE=1 ./scripts/install-launchagent.command   # 允许手机访问
```

日志：`~/Library/Logs/banxu-server.log`
卸载：`./scripts/uninstall-launchagent.command`

安装前需要先停止正在运行的班序进程，否则会提示端口占用。Windows/Linux 可分别使用「任务计划程序」/systemd，当前仓库未附带对应脚本。

## 12. 常见问题

| 现象 | 处理 |
|---|---|
| 页面提示「后端未更新」/ 保存设置报参数不合法 | 关闭旧后端进程，重新启动班序；版本自检会提示 |
| 端口 8000 被占用 | 已有班序在运行；直接打开 <http://127.0.0.1:8000>，或先停止旧进程 |
| 忘记口令 | `cat backend/data/.password` |
| PDF 无法导入 | 确认是学校导出的学生成绩单，且不是扫描图片；扫描件没有文字层暂不支持 |
| PDF 姓名匹配失败 | 检查名单姓名是否与成绩单一致；同名学生无法仅靠姓名匹配 |
| 手机打不开 | 确认用「手机访问」启动器、同一 Wi-Fi/Tailscale、IP 正确 |
| 更新失败 | 看 `backend/data/update.log`，重新运行 `./run.sh` |
| 数据误删 | 顶部「↶ 撤销」或 ⌘Z；也可从备份恢复 |

## 13. 隐私与开源

- 数据只保存在本机 SQLite，不主动上传服务器；
- 本仓库不包含任何学生数据、备份文件、口令；
- 开源协议：MIT（见 `LICENSE`）；
- 欢迎提交 Issue / Pull Request，但请勿上传真实学生信息或成绩。
