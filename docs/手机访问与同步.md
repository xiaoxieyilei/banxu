# 手机访问与同步（iPhone）

目标：手机和电脑共用同一份班级数据（电脑上的 SQLite），手机随时查看/修改，改完电脑立刻可见。

## 为什么能“同步”

没有额外的同步逻辑——数据只有一份，存在电脑上（`backend/data/banxu.sqlite3`）。
手机通过浏览器访问电脑上的同一服务，所以两边看到的永远是同一份数据。

## 前提

1. 电脑保持开机，班序服务在运行（macOS 双击 `启动班序（手机访问）.command`，Windows 双击 `启动班序（手机访问）.bat`）。
2. 电脑与手机都安装并登录 **同一个 Tailscale 账号**（免费，用于外出时也能访问）。
3. 知道访问口令（默认自动生成，见下文）。

## 第一步：启动服务（允许手机访问）

最简单：双击项目根目录的 **`启动班序（手机访问）.command`**（macOS）或 **`启动班序（手机访问）.bat`**（Windows），它会监听 `0.0.0.0:8000`。

或者在终端里：

```bash
cd "你的项目目录"
BANXU_HOST=0.0.0.0 ./run.sh
```

> 直接运行 `./run.sh` 时默认只监听 `127.0.0.1`，手机访问不到，这是安全的默认值。

口令来源（二选一）：
- 首次启动自动生成：`cat backend/data/.password`
- 启动时指定：`BANXU_PASSWORD=你的口令 ./run.sh`

## 第二步：安装 Tailscale（电脑 + 手机同一账号）

> 现在**同一 Wi-Fi 下已经可以直接用局域网地址访问**（见上一步的 `http://10.x.x.x:8000`）；
> 只有“外出用 4G”时才需要 Tailscale。

- 电脑：App Store 安装 Tailscale，登录。
- 手机：App Store 安装 Tailscale，登录同一账号。
- 电脑上查看 Tailscale IP（形如 `100.x.y.z`）：
  ```bash
  /Applications/Tailscale.app/Contents/MacOS/Tailscale ip -4
  ```
  或在 Tailscale 菜单栏图标里查看。

## 第三步：手机访问

1. 手机 Safari 打开：`http://<电脑的 Tailscale IP>:8000`
   （同一 Wi-Fi 下也可以用局域网地址，如 `http://10.2.203.155:8000`）
2. 输入访问口令 → 进入班序。
3. 点 Safari 分享按钮 → **添加到主屏幕** → 桌面出现「班序」图标，打开后全屏运行，像 App 一样。

## 安全说明

- 未登录访问任何 `/api/*` 都会返回 401，页面先显示口令登录框。
- 口令存于 `backend/data/.password`（或环境变量 `BANXU_PASSWORD`），Cookie 有效期 30 天；数据库、备份与口令文件权限均为仅本人可读写。
- Tailscale 是加密的私有网络，不向公网暴露端口；不要改用路由器端口映射直接暴露 8000。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开 | 确认电脑服务在跑、Tailscale 两端都登录、IP 是否填对 |
| 一直提示口令错误 | 重新 `cat backend/data/.password`，注意区分大小写 |
| 换电脑后要重输口令 | 换电脑即换服务，用新电脑的口令 |
| 数据要迁移 | 用页面右上角「备份到文件夹」或「导出备份」，在新电脑「恢复备份」 |

## 备份（与手机无关）

电脑每天 21:30 由软件自身检查并备份到当前用户 **文档目录/班序备份/班序备份-YYYY-MM-DD.json**；
软件启动时也会补一次备份，避免 21:30 时电脑没开机而漏备；
只有当天的数据有变化时才会生成，没有改动就跳过（不产生重复备份）；
手机端不需要单独备份。
